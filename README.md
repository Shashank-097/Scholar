# Cinema OTT Research — Next.js

A cinematic/editorial research website for cinema, OTT analysis, adaptation studies and contemporary screen culture.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Hero video

Place the final Higgsfield loop at:

`public/assets/higgsfield-hero-loop.mp4`

The page is already wired for autoplay, muted, loop and playsInline.

## Stack

- Next.js App Router
- React + TypeScript
- GSAP + ScrollTrigger
- CSS (no UI framework required)
